公开版本

未发布的源码改动不会自动进入 APK；安装包名称、应用身份和功能以当前公开 Release 的实际产物为准。

从旧版迁移

Rolithax Launcher 使用了新的应用身份。

旧版 MSLX Android 与 Rolithax Launcher 的包名和签名不同，不能直接覆盖安装。请先在旧版「设置 → 导出应用数据」创建加密备份（密码至少 8 位），再安装新版并通过「设置 → 导入应用数据」恢复。备份包含 Daemon 配置和 API Key；导入后，新安装会用自己的 Android Keystore 加密保存密钥。
